## 🚀 Featured Project – SafePath  
**MSc Dissertation Group Project | Safety-Aware Routing Platform**

🔗 **Repository:** https://github.com/KaranJoseph12/SafePath  
🌐 **Live Application:** https://safepath-deploy.vercel.app  
🎥 **Demo Video:** https://youtu.be/jXcPZIOq7zg  

**SafePath** is my **MSc dissertation group project**, built as a backend-driven platform that computes **safer urban routes** using historical datasets, spatial analysis, and real-time user inputs.

The system exposes **REST and WebSocket APIs**, consumed by a modern web client for route planning, hazard reporting, and live safety updates.

---

## 🧠 Backend & Systems Contributions
- Designed and implemented **safety-aware routing logic** combining crime density, collision risk, lighting coverage, and live hazards  
- Built **modular Express.js APIs** for routing, hazards, authentication, and buddy matching  
- Implemented **PostGIS spatial queries** (distance, buffers, bounding boxes) for safety scoring  
- Developed **CSV-based ETL pipelines** to ingest and normalise UK Police crime datasets

- Contributed to **system architecture, data flow design, and technical documentation**

## ⚙️ Core Technical Stack

**Backend**
- Node.js, Express.js  
- REST APIs & WebSocket services (Socket.IO)  
- JWT authentication, bcrypt password hashing  
- Multer (file uploads), Helmet (security middleware)

**Data & Spatial Systems**
- PostgreSQL 16+ with PostGIS  
- Spatial indexing and geospatial queries  
- CSV ingestion and ETL workflows  

**Frontend**
- Next.js (App Router), React, TypeScript  
- Tailwind CSS (responsive UI, dark/light mode)  
- Leaflet & React-Leaflet  
- Axios, Socket.IO Client

**External Services**
- UK Police Data API  
- OpenStreetMap & Overpass API  
- Nominatim (geocoding & reverse geocoding)  
- Cloudinary (media storage & delivery)
